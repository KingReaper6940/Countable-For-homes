# Real-record demo

1. Open the review queue and note the WPRDC snapshot date and limited coverage.
2. Open the Bedford development. Compare the parent application's 70-unit source claim with separate building permits for A3, A4, A7, and A8. Do not add parent and child counts or call the child subset the full project.
3. Select the A3 building permit and sprinkler record. Their repeated nine-unit description is supporting evidence for one building, not two additions.
4. Compare A3 and A4: a shared parcel does not merge distinct buildings. Inspect the temporary-use application, whose `Completed` status coexists with a description saying work under the A3 permit was pending.
5. Open the South Side conversion. Distinguish a proposal to add one dwelling from a resulting two-unit building. `Completed` remains a permit status, not an occupancy event date.
6. In Bedford, follow the source-investigation links to OneStopPGH and the City's separate occupancy search. Explain that neither a search link nor a permit status establishes occupancy; a reviewer needs a linked original document.
7. Open the ledger and export the CSV and evidence report. The selected permit snapshot has no verified addition because the needed occupancy evidence has not been supplied. Missing evidence does not mean zero homes were built.

The workflow uses selected real public permit records. It does not claim citywide completeness or a verified occupancy addition from permits alone.
